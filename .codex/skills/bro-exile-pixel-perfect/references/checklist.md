# Bro-exile Pixel Perfect Checklist

## Asset

- RGBA PNG.
- Non-empty alpha bbox.
- Expected `256x256` cell or documented exception.
- 64px preview.
- No chroma-key residue or visible halo.
- Runtime/harness preview when animated.
- Stage or roster capture when gameplay-facing.

## UI

- `--capture-ui` or relevant capture command ran.
- Text is visible in actual output.
- Dynamic values are visible.
- Buttons/cards do not overlap.
- Pixel UI fallback considered when font rendering is suspect.

## Report

- Commands.
- Output paths.
- Gate result.
- User approval need.
- Next owner lane.
