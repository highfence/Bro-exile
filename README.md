# Orebound Arena

An original arena survival baseline for experimenting with a Brotato-like loop and later adding mining, digging, and deep itemization.

## Play

Open `index.html` in a browser.

- `WASD` or arrow keys: move
- Mouse: aim direction
- `Space`: dash
- `P`: pause

## Current Loop

- Survive timed enemy waves in a compact arena.
- Weapons auto-fire at nearby enemies.
- Enemies drop XP crystals and ore.
- Leveling opens a three-card reward choice.
- Between waves, spend ore on weapons, healing, and upgrades.

## Next Growth Hooks

- Diggable arena tiles and ore veins.
- Tool-slot weapons that trade combat output for excavation.
- Biome layers with enemy and resource tables.
- Passive tree or atlas-style run modifiers.
- Item affixes, rarity, and socketable support gems.
