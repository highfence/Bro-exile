# Bro-exile 기획 문서 목차

이 문서는 Bro-exile의 기획 문서를 나중에 다시 찾기 쉽게 정리하는 허브다. 새 기획 문서를 만들거나 중요한 방향이 정리되면 이 파일에 링크와 현재 상태를 추가한다.

## 문서 상태 기준

- 현재 기준: 지금 개발 판단에 직접 참고할 문서.
- 탐색 중: 아이디어를 넓히는 중이며 아직 기준으로 확정하지 않은 문서.
- 구현 대기: 방향은 정했고, 구현 계획이나 프로토타입으로 옮길 수 있는 문서.
- 보관: 과거 판단 기록으로 남기지만 현재 방향과는 다를 수 있는 문서.
- 해결 기록: 버그나 기술 문제를 해결한 뒤 재발 방지를 위해 남기는 문서.

## 앞으로 문서를 관리하는 방법

- 새 아이디어 탐색은 `docs/brainstorms/`에 작성한다.
- 구현 순서와 작업 단위가 정해지면 `docs/plans/`에 계획 문서로 승격한다.
- 현재 개발 판단의 기준이 되는 문서는 이 목차의 `현재 먼저 볼 문서`에 올린다.
- 더 이상 기준이 아닌 문서는 삭제하지 말고 상태를 `보관`으로 바꾼다.
- 버그 해결, 기술적 시행착오, 재발 방지 지식은 `docs/solutions/`에 남긴다.
