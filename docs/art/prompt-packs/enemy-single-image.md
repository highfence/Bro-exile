# Enemy Single Image Prompt Pack

## Purpose

일반 적과 특수 적의 실사용 원본 후보를 만든다. 이 파일은 완성 스프라이트 시트가 아니라 **single image runtime enemy asset**을 요청하기 위한 prompt pack이다.

## Common Prompt

```text
Use case: stylized-concept
Asset type: 2D game enemy single-image sprite source for Bro-exile
Primary request: Create exactly one original cute-but-grotesque mine enemy, centered, designed as a single readable full-frame PNG for runtime bob/scale/flip animation.
Style/medium: original 2D painterly game sprite, thick dark outline, soft chunky shading, compact silhouette, cute exaggerated action toy proportions, mine-survival identity.
Composition/framing: one character only, full body, centered in a 1:1 square, generous padding, no ground shadow, no props outside the character silhouette.
Background: perfectly flat solid chroma-key background for background removal. The background must be one uniform color with no shadows, gradients, texture, floor plane, lighting variation, or reflection.
Constraints: no text, no watermark, no UI frame, no sprite sheet, no multiple poses, no multiple characters, no background scene, no cast shadow. Do not copy Brotato characters, icons, silhouettes, or decorative details.
```

## Shield Zombie Variant

```text
Create exactly one original cute-but-grotesque shield zombie miner enemy, centered, designed as a single readable full-frame PNG for runtime bob/scale/flip animation.

Subject: A squat undead miner creature with a cracked yellow hard hat and headlamp, pale moss-gray face, tiny worried glowing eyes, tattered orange-brown miner vest, stubby boots, and a large improvised front shield made from mine cart scrap and timber. The shield should clearly read as a defensive front-line enemy at 64px, but the character must remain cute and toy-like rather than scary.

Color palette: muted moss gray skin, dark outline, orange-brown vest, yellow helmet, teal ore accent used sparingly, shield in warm gray metal and brown timber. Avoid making the shield or body too yellow so it stays distinct from the player helmet.
```
