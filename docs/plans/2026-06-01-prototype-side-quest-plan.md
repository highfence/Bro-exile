# 프로토타입 사이드 퀘스트 계획

## 북극성

Bro-exile의 P1 목표는 “라운드 1부터 라운드 5까지 플레이 가능한 전투 게임이 되는가”를 검증하는 것이다.

이 목표는 기능 수가 아니라 플레이테스트 질문으로 판정한다.

- 전투 중: 플레이어가 각 라운드의 새 적 패턴을 읽고 대응하는가?
- 라운드 진행: 이전 몹이 누적되면서 점점 어렵고 다양한 상황이 되는가?
- 런 전체: 라운드 5 보스를 잡으면 한 번의 플레이테스트가 끝났다고 느끼는가?
- 검증 후: 무엇이 재미있었고 무엇이 흐렸는지 기록할 수 있는가?

## 1차 프로토타입 범위

### 포함

- 현재 Godot 루프를 기준으로 플레이한다.
- 5라운드 플레이테스트 루프를 만든다.
- 라운드마다 새 적 타입을 하나씩 소개한다.
- 이전 적 타입을 조연으로 누적해 전투 요구를 늘린다.
- 라운드 5에는 방어력 높은 보스 좀비를 배치한다.
- 보스를 처치하면 P1 플레이테스트를 종료한다.
- 라운드 사이에는 플레이어 체력을 완전히 회복한다.
- 플레이테스트마다 최소 지표와 관찰 메모를 남긴다.
- 아트는 최종 품질보다 가독성과 정체성 확인에 집중한다.

### 제외

- 장기 밸런스 완성.
- 보상 밸런스.
- 회복 자원 관리 밸런스.
- 계약 카드와 위험/보상 선택.
- 영구 성장, 메타 진행, 저장 시스템.
- 복잡한 PoE식 맵 관리, 크래프팅, 아틀라스.
- 모든 적/무기/아이템의 최종 에셋화.
- 자동화된 프로젝트 관리 UI.

## 퀘스트 체인

### 메인 퀘스트: 5라운드 플레이어블 루프

라운드 1부터 라운드 5까지 진행되고, 각 라운드가 다른 전투 요구를 소개하며, 마지막 보스를 잡으면 테스트가 끝나는 구조를 만든다.

관련 퀘스트:

- `001-ready-p1-playtest-lens.md`
- `004-ready-p1-p1-five-round-playable-loop.md`
- `005-ready-p1-enemy-archetypes-and-wave-patterns.md`
- `007-ready-p1-boss-zombie-and-test-ending.md`

### 전투 퀘스트: 읽히는 패턴 변화

기본 추격, 빠른 추격, 떼 압박, 원거리 투사체, 방어형 보스가 서로 다른 행동을 요구하는지 확인한다.

관련 퀘스트:

- `003-complete-p1-combat-readability-snapshot.md`
- `005-ready-p1-enemy-archetypes-and-wave-patterns.md`

### 정체성 퀘스트: 광산 게임처럼 보이기

플레이어, 적, 픽업, 무기 실루엣이 광산/안전모/공구 개조 판타지를 전달하는지 확인한다.

관련 퀘스트:

- `006-ready-p2-mining-identity-asset-pass.md`

### 이후 퀘스트: 보상과 위험/보상

P1에서 전투 루프가 성립한 뒤, 상점/보상/계약 카드가 빌드 방향과 위험 선택을 만드는지 확인한다.

관련 퀘스트:

- `009-complete-p2-contract-card-first-prototype.md`
- `010-pending-p2-corpse-explosion-pack-clear.md`
- `011-pending-p2-shop-and-reward-choice-pass.md`

## 진행 순서

1. 플레이테스트 렌즈를 먼저 만든다.
2. 현재 전투 화면의 가독성을 캡처 기준으로 정리한다.
3. 5라운드 플레이테스트 루프를 만든다.
4. 라운드별 적 타입과 누적 스폰 규칙을 만든다.
5. 라운드 5 보스와 테스트 종료 조건을 만든다.
6. 필요하면 광산 정체성 에셋 패스를 얹어 실제 크기에서 판단한다.
7. P1이 플레이 가능해진 뒤 계약/보상 퀘스트로 넘어간다.

## 플레이테스트 기록 형식

각 플레이테스트는 짧게 기록한다.

```text
날짜:
빌드:
도달 라운드:
가장 잘 읽힌 적 패턴:
가장 흐렸던 적 패턴:
가장 강했던 순간:
다음에 바꿀 것:
판정: keep / adjust / cut
```

기록은 처음에는 개별 퀘스트의 Work Log에 남긴다. 기록이 많아지면 `docs/playtests/`로 분리한다.

## 완료 기준

1차 프로토타입은 다음 질문에 답할 수 있으면 완료로 본다.

- 라운드 1-5가 중단 없이 진행되는가?
- 각 라운드의 새 적 타입이 구분되는가?
- 이전 라운드의 적이 누적되어 전투가 점점 다양해지는가?
- 라운드 5 보스를 잡으면 플레이테스트가 종료되는가?
- 현재 아트 방향은 작은 전투 화면에서 읽히는가?
- 다음 반복에서 키울 기능과 버릴 기능이 구분되는가?
