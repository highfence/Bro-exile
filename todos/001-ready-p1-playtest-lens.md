# 001. M1-D1 플레이테스트 렌즈 세우기

## Quest Card

- 목표: P1을 “라운드 5까지 플레이 가능한가”라는 기준으로 판단할 수 있게 만든다.
- 플레이어 감정: “한 판이 어디서 시작하고 어디서 끝나는지 안다.”
- 완료 보상: 이후 기능 추가가 P1 플레이어블 루프 위에 쌓인다.
- 실패 신호: 플레이 후 “그냥 아직 러프하다” 말고 남는 판단이 없다.

## Problem Statement

현재 게임은 기본 루프가 돌아가지만, P1에서 무엇을 기준으로 좋다/나쁘다를 판단할지 고정되어 있지 않다. P1은 보상이나 계약의 깊이가 아니라 5라운드 전투 루프의 성립 여부를 본다.

## Findings

- README 기준으로 20라운드 생존, 레벨업 보상, 상점, 자동 무기 루프가 이미 있다.
- 계약 카드와 팩 클리어 판타지는 문서로 정리되어 있지만 P1 범위는 아니다.
- P1은 기본 좀비, 빠른 좀비, 거미떼, 돌 던지는 좀비, 보스 좀비의 5라운드 구조를 검증한다.
- `--smoke-playtest`는 존재하지만 재미 판단을 위한 관찰 항목은 아직 없다.

## Proposed Solutions

### A. 수동 플레이테스트 체크리스트

짧은 Markdown 양식으로 매 테스트를 기록한다.

- 장점: 즉시 시작 가능.
- 단점: 기록 품질이 사람에 따라 흔들린다.
- 노력: 낮음.
- 위험: 낮음.

### B. 런 종료 후 리포트 UI

게임오버/승리 화면에 빌드, 계약, 킬, 광석, 피해량 같은 정보를 보여준다.

- 장점: 플레이 직후 기억이 살아 있을 때 판단할 수 있다.
- 단점: 구현 작업이 필요하다.
- 노력: 중간.
- 위험: 낮음.

### C. 자동 플레이테스트 로그

smoke playtest 결과를 JSON 또는 텍스트 로그로 저장한다.

- 장점: 반복 비교가 쉬워진다.
- 단점: 재미 판단은 여전히 수동 메모가 필요하다.
- 노력: 중간.
- 위험: 낮음.

## Recommended Action

먼저 A를 적용한다. 이후 008번 런 리포트에서 B와 C를 작게 붙인다.
