# 003. M1-D8 전투 가독성 스냅샷

## Quest Card

- 목표: 현재 전투 화면이 플레이어, 적, 탄환, 픽업을 즉시 구분하게 하는지 확인한다.
- 플레이어 감정: “내가 어디 있고, 무엇을 피하고, 무엇을 주워야 하는지 바로 보인다.”
- 완료 보상: 계약 카드와 팩 클리어 효과를 넣어도 화면 판단이 무너지지 않는다.
- 실패 신호: 피격 이유, 픽업 위치, 적 타입이 캡처만 봐도 흐리다.

## Problem Statement

전투가 러프한 도형 드로잉 상태라 기능 검증 전에 화면 가독성 문제가 재미 판단을 가릴 수 있다.

## Findings

- `scripts/main.gd`는 플레이어, 적, 탄환, 픽업을 직접 그린다.
- 플레이어는 현재 단순 사각형/원 조합이고, 최종 헬멧 마스코트 에셋과 다르다.
- UI 캡처 명령은 존재하지만 전투 가독성 전용 캡처/판정은 아직 약하다.

## Proposed Solutions

### A. 캡처 기반 수동 판정

기존 캡처/플레이테스트 명령으로 화면을 저장하고 체크리스트로 판단한다.

- 장점: 지금 바로 가능.
- 단점: 자동 판정은 없다.
- 노력: 낮음.
- 위험: 낮음.

### B. 디버그 오버레이 추가

피격 범위, 픽업 범위, 적 타입을 개발용 토글로 보여준다.

- 장점: 문제 원인을 찾기 쉽다.
- 단점: 실제 플레이 감각과 분리될 수 있다.
- 노력: 중간.
- 위험: 낮음.

### C. 임시 에셋 즉시 적용

플레이어/적/픽업을 현재 생성 에셋으로 바꿔 실전 크기에서 본다.

- 장점: 아트 방향 검증이 빨라진다.
- 단점: 에셋 정리 작업이 선행되어야 한다.
- 노력: 중간.
- 위험: 중간.

## Recommended Action

A를 먼저 실행하고, 흐린 부분이 확인되면 B 또는 C를 선택한다.

## Acceptance Criteria

- [ ] 현재 전투 화면 캡처 1장을 기준 이미지로 저장한다.
- [ ] 플레이어, 적, 탄환, XP, 광석의 구분 여부를 체크한다.
- [ ] 피격 이유가 불명확한 순간이 있는지 기록한다.
- [ ] 계약 카드/시체 폭발 추가 전에 고쳐야 할 가독성 이슈를 정한다.
