# 004. M1-D1 5라운드 플레이어블 루프

## Quest Card

- 목표: 라운드 1부터 라운드 5까지 이어지는 플레이 가능한 전투 루프를 만든다.
- 플레이어 감정: “짧지만 한 판이 끝났다.”
- 완료 보상: P1의 시작과 끝이 명확해진다.
- 실패 신호: 라운드가 길게 늘어지거나, 언제 테스트가 끝나는지 모른다.

## Problem Statement

현재 게임은 20라운드 생존 루프를 기준으로 만들어져 있다. P1 플레이 검증에는 너무 길고, 보상/상점/장기 밸런스가 전투 패턴 검증을 흐릴 수 있다.

## Findings

- P1 목표는 플레이어블한 게임이다.
- 보상은 P1의 핵심 검증 대상이 아니다.
- 라운드 5 보스 처치가 플레이테스트 1회의 종료 조건이다.

## Proposed Solutions

### A. P1 전용 5라운드 모드

현재 루프에 P1 플래그 또는 기본 설정을 두고 최대 라운드를 5로 제한한다.

- 장점: 현재 구조를 크게 흔들지 않는다.
- 단점: 기존 20라운드 상수와 분리 기준이 필요하다.
- 노력: 중간.
- 위험: 낮음.

### B. 기존 20라운드 루프를 5라운드로 축소

아예 현재 메인 루프를 P1 기준으로 바꾼다.

- 장점: 가장 단순하다.
- 단점: 이후 20라운드 확장으로 돌아갈 때 다시 손봐야 한다.
- 노력: 낮음.
- 위험: 낮음.

### C. 별도 P1 씬 생성

P1 검증용 씬을 새로 만들고 현재 게임과 분리한다.

- 장점: 테스트 조건이 깔끔하다.
- 단점: 코드/씬이 나뉘어 관리 비용이 생긴다.
- 노력: 중간.
- 위험: 중간.

## Recommended Action

B에 가깝게 시작한다. 지금은 P1이 주 개발 목표이므로 메인 루프를 5라운드 기준으로 단순화하고, 나중에 확장할 때 20라운드를 다시 열어도 된다.

## Acceptance Criteria

- [x] 최대 라운드가 P1 기준 5라운드로 동작한다.
- [x] 라운드 1-5가 중단 없이 이어진다.
- [x] 라운드 사이에 플레이어 체력이 완전히 회복된다.
- [x] 라운드 5에서 보스가 등장한다.
- [x] 보스 처치 시 승리/테스트 종료 화면이 나온다.
- [x] 라운드 사이 보상/상점은 P1 검증을 방해하지 않도록 최소화하거나 우회한다.
