# 005. M1-D1 적 아키타입과 웨이브 패턴

## Quest Card

- 목표: 5라운드 각각에 새 적 패턴을 하나씩 소개하고, 이전 적을 누적해 전투 요구를 늘린다.
- 플레이어 감정: “라운드가 넘어갈수록 다른 식으로 움직여야 한다.”
- 완료 보상: P1 전투가 단조로운 추격전에서 벗어난다.
- 실패 신호: 적 이름만 다르고 플레이 감각은 전부 똑같다.

## Problem Statement

P1이 플레이 가능한 게임이 되려면 각 라운드가 서로 다른 전투 문제를 던져야 한다. 단순히 적 수와 체력만 증가하면 라운드 5까지의 테스트가 지루해질 수 있다.

## Findings

- 라운드 1은 기본 좀비다.
- 라운드 2는 색 베리에이션이 있는 빠른 좀비다.
- 라운드 3은 체력 낮은 거미떼가 4-5마리씩 스폰된다.
- 라운드 4는 원거리에서 돌을 던지는 좀비다.
- 라운드 5는 방어력이 높은 보스 좀비다.
- 몹은 매 스테이지마다 새로 추가되고, 일부는 누적되어 점점 다양한 패턴을 만든다.

## Proposed Solutions

### A. 라운드별 주연 몹 + 조연 누적

각 라운드마다 새 몹을 주연으로 강하게 보여주고, 이전 몹은 낮은 비중으로 섞는다.

- 장점: 라운드별 검증 질문이 선명하다.
- 단점: 스폰 테이블을 명시적으로 관리해야 한다.
- 노력: 중간.
- 위험: 낮음.

### B. 완전 누적 스폰

새 몹이 추가되면 모든 이전 몹과 같은 비율로 계속 나온다.

- 장점: 구현이 단순하다.
- 단점: 새 몹의 특징이 묻힐 수 있다.
- 노력: 낮음.
- 위험: 중간.

### C. 라운드별 완전 독립 스폰

각 라운드에는 해당 라운드 몹만 나온다.

- 장점: 패턴 검증이 가장 명확하다.
- 단점: 누적 난이도와 복합 대응 감각이 약하다.
- 노력: 낮음.
- 위험: 중간.

## Recommended Action

A로 간다. “새 몹이 주연, 이전 몹은 조연” 구조가 P1 플레이테스트에 가장 잘 맞는다.

## Acceptance Criteria

- [x] 기본 좀비, 빠른 좀비, 거미떼, 돌 던지는 좀비, 보스 좀비 타입이 구분된다.
- [x] 라운드 2 빠른 좀비는 색과 속도로 기본 좀비와 구분된다.
- [x] 라운드 3 거미떼는 한 번에 4-5마리씩 스폰된다.
- [x] 라운드 4 돌 던지는 좀비는 원거리 투사체로 플레이어를 압박한다.
- [x] 라운드별 스폰 테이블이 새 몹을 주연으로, 이전 몹을 조연으로 다룬다.
