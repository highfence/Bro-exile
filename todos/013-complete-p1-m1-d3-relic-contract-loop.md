# 013. M1-D3 유물 계약 루프

## Quest Card

- 목표: 라운드 클리어 후 유물을 선택하고, 선택한 유물의 위험/보상이 런 끝까지 누적되게 만든다.
- 플레이어 감정: “이 위험은 지금 내 빌드라면 감당 가능하고, 보상이 맛있다.”
- 완료 보상: P2 상점 루프 위에 첫 위험/보상 선택 루프가 붙는다.
- 실패 신호: 유물을 골라도 다음 라운드나 상점 선택이 달라진 느낌이 없다.

## Problem Statement

P2는 라운드마다 상점에서 기존 드릴촉 무기에 부품을 붙이는 성장 루프를 만들었다. 하지만 플레이어가 스스로 난이도와 보상을 조절하는 순간은 아직 없다. P3에서는 광산에서 유물을 캐냈다는 설정으로, 라운드 클리어 후 누적 위험/보상 유물을 선택하게 만든다.

## Findings

- 기존 선택 overlay와 상점 overlay를 재사용할 수 있다.
- P2 상점은 다음 라운드 위협에 대응하는 부품을 보장하는 구조를 이미 갖고 있다.
- 유물은 상점보다 먼저 선택되어야, 플레이어가 방금 선택한 위험을 상점에서 대응할 수 있다.
- 유물은 전투 중과 상점 중 모두 아이콘으로 보여야 기억 부담이 줄어든다.

## Proposed Solutions

### A. 누적 유물 계약

라운드 클리어 후 유물 3개 중 하나를 선택한다. 선택한 유물은 런 끝까지 누적되고, 같은 유물도 다시 선택할 수 있다.

- 장점: 위험이 쌓이는 감각이 선명하다.
- 장점: P2 상점 대응 루프와 자연스럽게 맞물린다.
- 단점: 숫자 밸런스가 빨리 거칠어질 수 있다.
- 노력: 중간.
- 위험: 중간.

### B. 다음 라운드 한정 유물

유물이 다음 라운드에만 적용되고 사라진다.

- 장점: 밸런스가 쉽다.
- 단점: 유물이라는 이름의 누적 감각이 약하다.
- 노력: 낮음.
- 위험: 낮음.

### C. 유물 컬렉션형 패시브

유물은 위험 없이 장기 패시브 보너스만 준다.

- 장점: 보상감이 쉽다.
- 단점: P3 목표인 위험/보상 선택이 흐려진다.
- 노력: 낮음.
- 위험: 중간.

## Recommended Action

A로 간다. P3는 누적 위험/보상 선택을 검증하는 단계이므로, 같은 유물 중복 선택을 허용하고 위험과 보상을 모두 누적시킨다.

| 불안정한 폭약 결정 | 적 사망 시 위험 폭발 발생 | 폭발/광역 부품 등장 확률 증가 |

## Acceptance Criteria

- [x] 라운드 1-4 클리어 후 유물 선택 화면이 열린다.
- [x] 유물 후보 3개가 아이콘, 위험, 보상을 함께 보여준다.
- [x] 유물을 선택하면 그 다음 상점으로 이동한다.
- [x] 선택한 유물 효과가 런 끝까지 누적된다.
- [x] 같은 유물을 중복 선택할 수 있다.
- [x] 전투 HUD에서 현재 유물 아이콘을 확인할 수 있다.
- [x] 상점 화면에서 현재 유물 아이콘을 확인할 수 있다.
- [x] 승리/패배 화면에서 이번 런 유물 목록을 확인할 수 있다.
- [x] smoke playtest가 유물을 자동 선택하고 라운드 5 승리까지 도달한다.
