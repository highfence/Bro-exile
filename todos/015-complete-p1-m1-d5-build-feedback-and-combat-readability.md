# 015. M1-D5 빌드 체감과 전투 가독성

## Quest Card

- 목표: 상점에서 붙인 부품과 선택한 유물이 전투 화면에서 즉시 다르게 느껴지게 만든다.
- 플레이어 감정: “방금 산 부품 덕분에 이 위험을 감당했다.”
- 완료 보상: P3의 유물 위험과 P2의 상점 대응이 전투 안에서 체감된다.
- 실패 신호: 부품을 사도 숫자만 바뀌고, 화면에서는 빌드 차이가 거의 느껴지지 않는다.

## Problem Statement

P4는 플레이테스트 결과를 복기할 수 있게 만들었다. 이제 P5에서는 관통, 폭발, 방어 관통, 공속, 사거리, 이동 속도 같은 대응 능력이 전투 중에 읽혀야 한다. 특히 거미팩, 투척 좀비, 엘리트, 보스처럼 P1/P3가 만든 위험을 플레이어가 “어떤 부품으로 극복했는지” 알아차릴 수 있어야 한다.

## Priority Feedback Targets

| 대상 | 확인할 체감 |
| --- | --- |
| 관통 드릴촉 | 적을 지나가는 궤적과 다중 히트가 보인다. |
| 파편 폭약 | 폭발 반경과 직격 피해가 명확하다. |
| 균열 탄심 | 보스/엘리트에게 방어 관통 히트가 구분된다. |
| 급속 방아쇠 | 발사 리듬이 빨라졌다는 감각이 난다. |
| 긴 총열 | 사거리와 탄속 증가가 체감된다. |
| 스프링 장화 | 투척 좀비 대응과 거리 재조정이 쉬워졌다는 감각이 난다. |

## Acceptance Criteria

- [x] 최소 4개 핵심 부품이 서로 다른 시각 피드백을 가진다.
- [x] 폭발+관통 조합이 거미팩과 보스 모두에서 읽힌다.
- [x] 보스 HP/피격 피드백이 명확해서 데미지 누락처럼 느껴지지 않는다.
- [x] 유물 위험에 맞는 대응 부품을 샀을 때 전투가 다르게 느껴진다.
- [x] P4 런 리포트에서 P5 변경 후 빌드/부품 선택이 확인된다.
- [x] UI/전투 캡처로 가독성을 확인한다.

## Suggested First Pass

1. 관통 드릴촉과 파편 폭약의 궤적/반경 피드백을 먼저 강화한다.
2. 보스와 엘리트에게 피격 flash, HP 변화, 방어 관통 텍스트를 더 명확히 준다.
3. 거미팩이 폭발/관통에 정리되는 순간을 캡처할 수 있는 debug 또는 capture 커맨드를 만든다.
4. `--smoke-playtest`, `--debug-boss-pierce-splash`, P4 런 리포트로 회귀를 확인한다.

**Learnings:**
- 새 VFX 시스템을 만들지 않아도 기존 spark/floating text 구조에 색, 길이, 폭, 방향성만 추가해 부품 차이를 충분히 만들 수 있다.
- 방어 관통처럼 중요한 피드백은 보스 중앙에 묻히기 쉬우므로 텍스트 위치와 그림자가 필요하다.
- 몹 속도 조정은 단독으로는 부족하고, separation과 함께 들어가야 무리 압박은 유지하면서 겹침이 줄어든다.
