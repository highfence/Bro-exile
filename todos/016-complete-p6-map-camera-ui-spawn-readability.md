# 016. P6 넓은 광산과 전투 화면 정리

## Quest Card

- 목표: 화면과 맵을 분리하고, 전투를 가리지 않는 UI와 화면 안 스폰 예고를 만든다.
- 플레이어 감정: “광산 공간이 넓어졌고, 위험이 어디서 생기는지 답답하지 않게 읽힌다.”
- 완료 보상: 전투가 화면 가장자리/고정 UI에 갇히지 않고, 이동과 포지셔닝이 의미를 갖는다.
- 실패 신호: 맵이 여전히 한 화면짜리처럼 느껴지고, UI가 몹을 가리거나 몹이 갑자기 화면 밖에서 튀어나온다.

## Problem Statement

현재 Godot viewport와 월드 크기는 모두 `1280x720`이라, 보이는 화면이 곧 전체 맵이다. Switch 2 기준 화면비도 16:9이고 우리 viewport도 16:9이므로 답답함의 핵심은 화면비가 아니라 월드/카메라 분리가 없다는 점이다. 또한 하단 HUD가 전투 몹을 가려 답답하고, 스폰이 화면 밖에서 발생해 위험을 미리 읽기 어렵다.

## P6 Target

P6는 새 전투 시스템을 늘리기보다 전투 공간과 읽기 경험을 정리한다.

- viewport는 `1280x720` 16:9를 유지한다.
- 월드는 `2048x2048` 정사각형으로 확장한다.
- 플레이어를 따라가는 카메라를 추가한다.
- 맵은 화면 바깥까지 펼쳐져야 하며, 이동 중 카메라가 월드 경계를 넘지 않게 한다.
- 전투 중 UI는 몹을 가리지 않도록 투명하거나 최소화한다.
- 하단 무기/유물 HUD는 전투 중 제거한다.
- 유물 선택/상점/일시정지 화면에서 현재 상태를 확인할 수 있게 한다.
- `ESC`를 누르면 일시정지창이 뜨고, 그 안에서 체력/광석/무기/부품/유물/런 리포트 핵심 상태를 확인할 수 있다.
- 스폰은 화면 밖에서 갑자기 나오지 않는다.
- 브로테이토처럼 화면 안에서 먼저 스폰 위치를 예고한다.
- 스폰 예고는 땅에서 흙이 들썩이는 이미지/애니메이션으로 표현한다.
- 예고가 끝나면 몹이 땅 아래에서 위로 뿅 올라오는 등장 애니메이션으로 나온다.

## Acceptance Criteria

- [x] `VIEW_SIZE`와 `WORLD_SIZE` 개념이 분리된다.
- [x] viewport는 `1280x720`, 월드는 `2048x2048`로 동작한다.
- [x] 플레이어 추적 카메라가 있고, 카메라는 월드 경계를 벗어나지 않는다.
- [x] 플레이어 이동, 탄, 적, 픽업, 스폰, 배경 그리드가 확장된 월드 기준으로 동작한다.
- [x] 전투 중 하단 HUD가 사라지거나 몹을 가리지 않는 형태로 정리된다.
- [x] 전투 중 필수 HUD는 투명/최소화되어 적과 탄을 읽는 데 방해가 적다.
- [x] 유물 선택과 상점 화면에서 현재 무기/부품/유물/광석/체력 상태를 확인할 수 있다.
- [x] `ESC` 일시정지창에서 현재 상태를 확인하고 재개/재시작을 선택할 수 있다.
- [x] 적은 화면 밖에서 바로 스폰되지 않고, 화면 안 안전한 위치에 스폰 예고가 먼저 나타난다.
- [x] 스폰 예고는 흙이 들썩이는 애니메이션으로 최소 0.6초 이상 보인다.
- [x] 예고 후 몹이 땅 아래에서 위로 올라오는 등장 애니메이션을 가진다.
- [x] 기존 P3/P4/P5 debug/smoke 회귀가 통과한다.
- [x] 넓은 맵/카메라/스폰 예고를 확인하는 캡처 또는 debug 커맨드가 있다.

## Suggested Implementation Phases

### Phase 1: 월드와 카메라 분리

- `VIEW_SIZE := Vector2(1280, 720)` 추가
- `WORLD_SIZE := Vector2(2048, 2048)`로 확장
- 플레이어 중심 카메라 오프셋 또는 `Camera2D` 도입
- 월드 좌표와 화면 좌표가 섞인 draw/input/HUD 코드를 정리

### Phase 2: 전투 HUD 정리

- 하단 무기 HUD와 하단 유물 HUD를 전투 중 제거
- 상단 HUD는 투명도를 높이고, 필요한 수치만 유지
- 선택/상점/일시정지 overlay에는 현재 상태 패널을 추가

### Phase 3: 일시정지 상태창

- `ESC`/pause 입력 시 단순 배너 대신 pause overlay를 표시
- 체력, 광석, 현재 라운드, 선택 유물, 무기 부품, 주요 런 통계를 보여준다.
- 재개/다시 시작 버튼을 둔다.

### Phase 4: 화면 안 스폰 예고

- 즉시 적 생성 대신 `spawn_warnings` 상태를 추가한다.
- 현재 카메라 화면 안이면서 플레이어와 너무 가깝지 않은 위치를 고른다.
- 흙 들썩임 링/먼지/작은 균열 애니메이션을 먼저 보여준다.
- 예고 시간이 끝나면 적이 아래에서 위로 등장하고 전투에 합류한다.
